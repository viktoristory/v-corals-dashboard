☁ Data source: Google Sheets (private, sign-in required)
This dashboard holds no readings of its own — every load pulls live from your private Google Sheet. One-time setup: create an OAuth 2.0 Client ID ("Web application") in Google Cloud Console, enable the Google Sheets API, and add this page's URL under "Authorized JavaScript origins". The Client ID is a public identifier (not a secret) — it's safe to leave visible in this page's source.

Who can actually get in: anyone can attempt to sign in, but Google Sheets API only returns data to accounts your Sheet is already shared with — the sharing list on the Sheet itself is what restricts access, not this page. For a company rollout, using a Google Workspace "Internal" OAuth app additionally limits sign-in to your organization's accounts. Add or remove people via the Sheet's normal "Share" dialog.

Add a Notes column to any system tab — any day with text there gets a marked point on the chart with the note shown on hover.
